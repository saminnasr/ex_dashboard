راهنمای راه‌اندازی داشبورد مراجعین نمایشگاه
===========================================

محتویات پوشه
------------
1) index.html       صفحه داشبورد
2) styles.css       طراحی ظاهری واکنش‌گرا
3) app.js           فیلترها، جستجو، مرتب‌سازی، صفحه‌بندی و خروجی
4) config.js        محل واردکردن آدرس و کلید عمومی Supabase
5) supabase_setup.sql کد ساخت جدول و دسترسی فقط‌خواندنی
6) exhibition_visitors.csv اطلاعات استخراج‌شده از فایل اکسل شما برای ورود به Supabase

مرحله ۱ ـ ساخت جدول
-------------------
1. وارد پروژه Supabase شوید.
2. از منوی SQL Editor گزینه New query را بزنید.
3. تمام محتوای فایل supabase_setup.sql را اجرا کنید.

مرحله ۲ ـ ورود اطلاعات Excel
----------------------------
1. در Supabase به Table Editor بروید.
2. جدول exhibition_visitors را باز کنید.
3. گزینه Insert و سپس Import data from CSV را انتخاب کنید.
4. فایل exhibition_visitors.csv را انتخاب و Import کنید.
5. ستون‌ها باید با نام‌های visitor_name, company, activity_service, phone, extra_notes
   تطبیق داده شوند. ستون id و created_at را وارد نکنید؛ خودکار ساخته می‌شوند.

نکته: ستون پنجم فایل اولیه عنوان نداشت؛ برای حفظ اطلاعات آن، نام
«توضیحات تکمیلی» (extra_notes) در نظر گرفته شده است. محتوای سلول‌ها تغییر داده نشده.
شماره تماس‌ها به‌صورت متن ذخیره می‌شوند تا صفر ابتدایی یا قالب شماره از بین نرود.
مقدار «۱۷۰ مگاوات» که در فایل اولیه داخل ستون شماره تماس بوده، عیناً حفظ شده است؛
قبل از انتشار داشبورد بهتر است آن ردیف را در فایل/جدول بررسی کنید.

مرحله ۳ ـ اتصال داشبورد به Supabase
----------------------------------
1. در Supabase وارد Project Settings > API شوید.
2. Project URL و کلید anon / publishable را کپی کنید.
3. فایل config.js را با ویرایشگر متن باز کنید.
4. مقادیر زیر را جایگزین کنید:
   window.SUPABASE_URL = "آدرس پروژه";
   window.SUPABASE_ANON_KEY = "کلید عمومی anon یا publishable";
5. فایل را ذخیره کنید.

هشدار امنیتی مهم:
کلید anon/publishable برای قرار گرفتن در کد مرورگر طراحی شده است؛
هرگز service_role یا secret key را در config.js قرار ندهید.
به‌دلیل policy عمومی این پروژه، هر کسی که به API پروژه و نام جدول دسترسی داشته باشد
می‌تواند اطلاعات این جدول را بخواند. لینک داشبورد محرمانگی ایجاد نمی‌کند.
همه شماره‌ها و اطلاعات تماس این جدول برای عموم قابل خواندن خواهند بود.
دسترسی نوشتن در policy این پروژه داده نشده است.

مرحله ۴ ـ تست روی کامپیوتر
-------------------------
داخل پوشه پروژه ترمینال باز کنید و اجرا کنید:
  python -m http.server 8080
سپس در مرورگر باز کنید:
  http://localhost:8080

مرحله ۵ ـ انتشار برای معاونین
-----------------------------
فایل‌های index.html, styles.css, app.js و config.js را روی یک هاست استاتیک
مانند Netlify، Vercel یا هاست شرکت قرار دهید. بعد از انتشار، لینک سایت را
برای معاونین بفرستید. فایل CSV و supabase_setup.sql لازم نیست روی هاست عمومی
قرار بگیرند.

امکانات
-------
- آمار کل رکوردها، نام‌ها، شرکت‌های یکتا و شماره‌های تماس
- نمودار ۵ مقدار پرتکرار حوزه فعالیت/خدمات
- جستجوی سراسری در تمام ستون‌ها
- فیلتر مستقل برای هر ۵ ستون و فیلتر ترکیبی
- مرتب‌سازی صعودی/نزولی با کلیک روی عنوان ستون
- صفحه‌بندی و انتخاب تعداد ردیف
- خروجی CSV از نتایج فیلترشده (قابل بازشدن با Excel)
- رابط فارسی و راست‌چین، سازگار با موبایل و دسکتاپ

توجه: داشبورد داده‌های جدید را هنگام بارگذاری یا با دکمه بروزرسانی دریافت می‌کند.
برای تغییر اطلاعات، از Table Editor در Supabase استفاده کنید.
